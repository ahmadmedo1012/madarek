## الأدلة التفاعلية (بلا لقطات — تأكيدات حيّة في المواصفة)
- **لا فيض أفقي** عند ‏{320, 360, 390, 768, 1440} × ‏النمطين: ‏`documentElement.scrollWidth ≤ innerWidth` (سلّم `.table-wrap` الداخلي وحده مستثنى).
- **السكّة المطموسة**: زر الطي يبدّل `html[data-sidebar-collapsed]` والعرض ‏256⇄64، و`aria-label` يعوّض التسمية المطموسة، ‏Ctrl+B يعمل، والحالة تصمد عبر إعادة التحميل.
- **صدق المسار النشط**: ‏`.nav-item.on` واحدة بالضبط بعنوانها في الشريط والترويسة و`document.title`، والرجوع يستعيد التمرير (مراقب الـPOP المحدود ~1s).
- **لغة الطبقات**: Escape يغلق قائمة المستخدم ويعيد التركيز إلى المُطلِق؛ ⌘K تفتح/تُصفّي/تُغلق؛ Ctrl+B معطّل واللوحة مفتوحة.
- **ثبات السمة**: مبدّل الشريط يقلب الداكن→الفاتح ويصمد عبر إعادة التحميل.
- **لوحة المفاتيح فقط**: رابط التخطي أول وقفة، Enter يقفز إلى ‏#main، حلقة `:focus-visible` ظاهرة.
- **الحركة المخفّضة**: الدرج فوري (حزام ‏0.01ms) وصفر أنيميشن جارٍ على القشرة.
