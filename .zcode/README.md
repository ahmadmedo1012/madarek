# .zcode/ — أدوات وكيل zcode (عام، غير خاص بمشروع مدارك)

مكتبة «شخصيات» وكلاء عامة لأداة `.zcode` — ملفات وصف بصيغة
`name:` / `description:` + منهج عمل لكل دور.

> **تنبيه:** هذه الملفات **عامة وغير مضبوطة على مدارك** — كثير منها لمجالات لا
> علاقة له بالمشروع (Drupal، WordPress، Solidity، WeChat…). لا تعتبرها وثائق
> مشروع، ولا تستخدمها كدليل على بنية مدارك أو ممارساته.

- مصدر الحقيقة لفهم المشروع: `AGENTS.md` (الجذر) ثم `docs/README.md`.
- لأدوار العمل على هذا المستودع تحديدًا: انظر `AGENTS.md` وقسم «الملفات
  المرجعية قبل العمل على كل وحدة» فيه.
