## ١) توثيق نطاق الإرسال (مرة واحدة، ~10 دقائق)

مفتاح API الحالي مقيّد بالإرسال فقط، لذا تُدار النطاقات من لوحة Resend:

١. من https://resend.com/domains اضغط **Add Domain** واختر نطاقًا فرعيًا
   مثل `mail.smart-link.ly` (أو النطاق الذي تريده للإرسال الرسمي).
٢. ستظهر لك سجلات DNS الثلاثة (SPF / DKIM ×2 — وأضِف DMARC إن ظهر):
   انسخها كما هي.
٣. من لوحة تحكم DNS لنطاقك أضِف السجلات (TXT و CNAME كما هو مبين).
٤. عد إلى Resend واضغط **Verify** — تفعّل خلال دقائق عادةً.
٥. أخبر الجلسة البرمجية حتى تُحدَّث فحوصات الإرسال تلقائيًا.

## ٢) ضبط متغيرات البيئة في Render (٣ حقول، دقيقتان)

من https://dashboard.render.com → خدمة **madarek** → Environment:

```
MAIL_PROVIDER = resend
MAIL_API_KEY = <المفتاح الحالي re_fGM2…>
MAIL_FROM    = مدارك <no-reply@mail.smart-link.ly>   # بعد توثيق النطاق
MAIL_REPLY_TO = ahmadmedo1012@gmail.com              # اختياري لكن مفيد
```

ثم **Save** — تُعاد الخدمة تلقائيًا وتفحص الإقلاع المفاتيح (تفشل الإقلاة
فورًا إن نسيْت حقلًا — هذا صمام الأمان المقصود).

> قبل توثيق النطاق يمكن ترك `MAIL_PROVIDER` فارغًا (الوضع الصادق «none»:
> لا يُرسَل شيء ويُسجَّل الإسقاط) — استخدم `MAIL_FROM =
> مدارك <onboarding@resend.dev>` فقط للتجربة على بريدك الشخصي.
