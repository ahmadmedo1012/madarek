# 01 — نظرة عامة على مدارك

## ما هو مدارك؟

**مدارك (Madarek)** هي منصة التعلّم الذكية الرسمية لـ**جامعة الزاوية** —
التابعة لوزارة التعليم العالي والبحث العلمي في ليبيا — وهي تطبيق ويب واحد
عربي بالكامل (RTL) يجمع في خدمة واحدة: الواجهة التعريفية، ومنصة تعلم إدارية
(LMS) كاملة، وأدوات الإدارة الأكاديمية، وقطاع رقابة الجودة.

تقنيًا، مدارك مستودع واحد (monorepo) يضم:

- **خلفية (backend/)**: Express + TypeScript + Prisma 5 فوق PostgreSQL
  (استضافة Neon)، تخدم واجهات برمجية تحت `/api/v1/*` وتخدم الواجهة المبنية
  نفسها في الإنتاج — خدمة واحدة.
- **واجهة (frontend/)**: React 18 + Vite + TypeScript، بتصميم عربي أصيل
  بنظام رموز تصميم (design tokens) وسمتين: ليلية «ذهبي على ليلي» ونهارية
  «نحاسي على كريمي».
- **نشر**: Render (خطة مجانية، إقليم virginia) مع نشر تلقائي عند كل دفع
  إلى `main`.

لغة التصميم الكاملة موثقة في [`DESIGN.md`](../DESIGN.md)، وزوج تصدير
التكافؤ مقيّد ببوابة تحقق آلية موصوفة في
[PARITY-EXPORT.md](PARITY-EXPORT.md).

## المشكلة التي يحلها

تدير جامعة حكومية كبيرة (25 كلية موزعة على campuses الزاوية والعجيلات
وزوارة) عمليات تعليمية متفرقة: محاضرات مسجلة بلا تتبع مشاهدة، تقييم
بلا صورة إتقان لكل مفهوم، بحوث طلابية تُسلَّم ورقيًا بلا دورة مراجعة،
وضعف رؤية إدارية مؤسسية. مدارك يوحّد هذه الدوائر في منصة واحدة بسياق
عربي كامل، ويعطي كل دور «قطاعه» الخاص:

- **الطالب**: جدول ومقرراته، محاضرات معكوسة بأسئلة إدماجية، مصفوفة إتقان
  تكشف فجواته، دورة بحث علمي كاملة، مكتبة وموظف مستقبل وتدريب ذاتي.
- **الأستاذ**: لوحة مؤشرات، تحليلات لكل شعبة، نموذج مخاطرة مبكر للطلاب،
  تأليف منهج (فصول/أسئلة إدماجية)، تصحيح البحوث بشروح داخلية.
- **الإدارة (ADMIN)**: كليات ومقررات، تقارير من قاعدة البيانات فعليًا،
  صلاحيات دقيقة، مزامنة حقائق الجامعة.
- **ضمان الجودة (QUALITY)**: قطاع رقابة قرائي فقط — صحة المقررات، أداء
  الأساتذة، التفاعل، شجرة المناهج، رقابة الاختبارات.
- **المالك (OWNER)**: مؤشرات المنصة، حاكمية الأدوار (بحراس آخر مالك
  نشط)، سجل تدقيق كامل، حالة النظام والتنبيهات التشغيلية.

## الحالة الحالية (بصدق، من الشيفرة والتاريخ)

| البند | الحالة |
|---|---|
| الميزات الأساسية للخمسة أدوار | **منفَّذة ومشحَنة** — اختبارات 1015 واجهة + 1021 خلفية خضراء (2026-10-10) |
| نظام التصميم والسمتان | منفَّذان؛ بوابة تكافؤ 163/163 خضراء |
| مساعد الذكاء الاصطناعي | **محلي قالبية** — لا نموذج لغوي خارجي؛ يؤلف ردودًا واعية بفجوات الطالب |
| فحص الانتحال والمحتوى الآلي للبحوث | **محاكاة حتمية معلنة** — نسب رمزية ثابتة المدى؛ فقط استخراج نص PDF حقيقي (انظر [02-features](02-features.md)) |
| طبقة i18n الإنجليزية | **غير منفَّذة** (كل نصوص الواجهة عربية صريحة) |
| اختبارات E2E وقاعدة بيانات اختبارية | غير موجودة — التغطية وحدات نقية بلا DB (انظر [11-testing](11-testing.md)) |
| رفع الملفات | غير موجود؛ ملفات البحوث تُقرأ من مستودع الشيفرة (انظر [12-deployment](12-deployment.md)) |

سجل الجولات (rNNN) والتاريخ الكامل: [`CHANGELOG.md`](../CHANGELOG.md)
وسجل الالتزامات. ترقيم الجولات يبدأ من «برنامج التكافؤ» الموحد لنظام
التصميم (انظر `DESIGN.md`).

## الفئات المستهدفة

1. **طلاب الجامعة** — الاستخدام اليومي: المحاضرات، الواجبات، البحوث، المكتبة.
2. **أعضاء هيئة التدريس** — إدارة الشعب وتتبع الطلاب وتصحيح البحوث.
3. **إدارة الجامعة** — الكليات والمقررات والتقارير والصلاحيات.
4. **مكتب ضمان الجودة** — رقابة مؤسسية قرائية عبر قطاع مستقل.
5. **مالك المنصة** — التشغيل والحاكمية والمؤشرات.
6. **فريق التطوير/الصيانة** — والوكلاء الذكيون: انظر [`AGENTS.md`](../AGENTS.md).
