## 6. الفجوات المتبقية بصدق (الطريق إلى 9+/10)

1. **إحساس «المشاهد المثبتة»**: المرجع scroll-jacked بالكامل (e-pin). عندنا تمرير أصلي (صحيح لجامعة) لكن المشاهد لا «تتحول» كما يفعل — إضافة تحولات مشهدية خفيفة (fade/scale بين الفصول) هي الخطوة التالية الأكبر.
2. **الرحلة (journey)**: البطاقات المتناوبة تقرأ فراغًا قطريًا؛ مرشّح مستقبلي: مشهد أفقي مثبت أو شبكة صارمة.
3. **فوتر** ما زال أثقل من مرجع (وظيفي: روابط حقيقية) — مقبول كحل وسط.
4. **طباعة**: يمكن رفع تباين الأحجام أكثر (h2 → 4rem+).
5. Preloader/بوابة دخول (لدى المرجع طقس دخول) — المكونات جاهزة (PreloaderRitual) لكن غير مفعّلة عمدًا حتى لا نؤخر وصول المستخدم للمحتوى.
