- **الأثر**: الطالب يفتح الدرس فيرى خطأ تحميل؛ يكسر الثقة فورًا ويجعل النقاط التفاعلية (checkpoints عند 200/280/560ث) غير قابلة للوصول أبدًا.
- **القرار**: إصلاح جذري — فيديو محلي مستضاف ذاتيًا 100% أصلي.
- **التنفيذ المنفّذ**: وُلّدت 3 فيديوهات (600/720/540ث، ‏854×480، ‏~2.4MB إجمالًا) ببطاقات فصول بهوية Orbit Ink عبر Playwright+ffmpeg (`scripts/lecture-video/`) → `frontend/public/lectures/se301-0{1,2,3}-*.mp4` · وُسّع نمط الـURL الخلفي لقبول مسارات نفس الأصل (`isSanctionedMediaUrl`) · أُعيدت كتابة تعريفات المحاضرات في `seed.ts` بالتوقيتات الكاملة الصادقة المطابقة لحدود بطاقات الفيديو (فصل عند 180/240/480ث… ونقاط عند 200/280/560/250ث) · بعد النشر تُحدَّث روابط الإنتاج عبر `PATCH /lectures/:id` بحساب admin.
- **التحقق**: إطارات الفيديو عُرضت على VLM («عالية الجودة، بلا عيوب») · اختبارات العقد الجديد 51/51 · بعد النشر: فتح الدرس = فيديو يعمل + نقطة تفاعل تظهر عند ثانيته.

### GAP-2 【P0 ✅ نُفّذ】 Hero يفتقد العمق والجاذبية — الانطباع الأول «آمن لكن يُنسى» (VLM 5.5/10)
