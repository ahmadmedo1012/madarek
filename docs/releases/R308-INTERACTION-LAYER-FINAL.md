## B. النظام المُنفَّذ (مصفوفة التكافؤ A–H كاملة)

- **الناظم الواحد** (`lib/motion/sheetConductor.ts`): ساعة rAF واحدة يشترك فيها كل
  مؤثّر وينسحب عند الخمول — الصفحة الساكنة بصفر إطارات مستيقظة (مؤشّر فحص
  `window.__sheetConductor` يثبته اختبار الوحدة وسيناريو المتصفح).
- **لوحة البدء** (`SheetLoader`): تقدّم صادق مربوط بالخطوط + حدث التحميل (4+26+70)،
  رسم خطّي متدرّج بترتيب مقصود، مسطرة وقراءة إحداثيات، سجلّ تهيئة عربي صادق، خروج
  قصّ مركزي — مرة لكل جلسة (sessionStorage)، «تخطّي» دائم، وتُتخطى كليًا مع تقليل
  الحركة أو غياب matchMedia.
- **أداة الإشارة** (`SheetCursor`): مربّع 9px بلون الإشارة على Canvas (lerp 0.18)،
  ذيل سرعة فوق 1.5px/إطار بتدرّج ألفا تربيعي يختفي عند أول إطار ساكن، تقليص
  استهداف عند الضغط (0.56/0.68)، مناطق `data-cursor="hidden"`، ولوحة أرضية تحت
  النقطة تضمن القراءة فوق الصور والسمة الداكنة. للمؤشّرات الدقيقة فقط.
- **محطات الفحص** (`HeroInspect`): أدلّة + قراءة `X/Y` نسبية للمشهد + سحب بعتبة
  2px وخانة تحديد بحدّ مرجاني وتدرّج يتبع اتجاه السحب، تنشيط AABB لثلاث محطات
  معاد إسقاطها عبر تحويل viewBox الحقيقي (letterbox — اختبار وحدة على ٣ مقاييس)،
  تبقى مفتوحة بعد الإفلات مع «إعادة ضبط» صريحة، والأزرار الساخنة تبقى مسار
  الوصول الشامل.
- **رحلة التعلّم** (`JourneyScene`): مسار 480dvh بتثبيت CSS sticky (لا JS pin)،
  الرسم الأصلي نفسه (`BlueprintSvg`) يستمر بينما تتقاطع طبقات المراحل مع التمرير،
  المحطات المرقّمة تعبر النافذة، وعمود القدرات يتمدّد (0→34vw) في نهاية التثبيت.
  فصول 01–04 انتقلت هنا؛ 05–06 بقيت صفوف دفتر مسطّحة. ≤991px: تسلسل مقروء مكدّس.
- **الحبر** (`InkSketch`): قناع تربيعي `M 0 y Q 50 1.25y 100 y` يكتسح من أعلى
  لأسفل مع سلسلة اضطراب المرجع نفسها (feTurbulence .045/.055/4/5 → displacement
  100 → blur 1.8 → alpha 2.2/−0.6) — فوق الصور فقط عبر خانة `overlay` الجديدة في
  MediaFrame؛ التسميات والتراخيص ظاهرة دائمًا.
- **شريط الفحص** (`FooterLens`): عدسة مؤشّر (r≈99 + نبضة 1.05×، lerp ‏0.09/0.15،
  ينام عند الاستقرار) تكشف الرسم المحلول فوق المسودة؛ ثابت محسول على اللمس/الRM.
- **مغادرة اللوحة** (`sheetExit`): كسح هندسي عند الروابط الداخلية الخارج — لا يؤخّر
  التنقّل أبدًا (قمع الدخول محفوظ 5+5)، ويتخطى مع تقليل الحركة.
- **كشف الكلمات** (`WordReveal`/`ScrubReveal`): تقسيم على الفراغات فقط (فصل الكلمات
  آمن للتشكيل العربي — تعديل DESIGN.md §4 موثّق، وعقد السلامة مثبّت باختبار).
  عنوان البيان مربوط بالتمرير (قابل للعكس).
- **مؤثّرات مستمرة**: شريط القدرات (marquee RTL)، نبض المحطات، زحف حلقات المراحل،
  ومسح لوحة البدء — كلها `@keyframes` مدرجة في قائمة بيضاء مثبّتة باختبار، وتنهار
  جميعها مع تقليل الحركة.
