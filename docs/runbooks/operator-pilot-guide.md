# دليل المشغّل والطيار — Operator & Pilot Guide (r187)

> دليل عمليّ مضغوط لعرض مدارك أمام جامعة وتشغيل تجربة طيار
> محدودة (5–10 طلبة). كل خطوة هنا **مُتحقَّقة على المنتج الحقيقي**
> (راجع [جاهزية الإطلاق](../launch-readiness.md) للأدلة).
> **لا أسرار في هذا الملف** — كلمات مرور الحسابات التجريبية
> موثّقة في [12-deployment](../12-deployment.md) (بذرة seed.ts)؛
  كلمة مرور المالك سُلّمت للمشغّل خاصة ولا تُكتب هنا أبدًا.

---

## قبل العرض (تحقّق 5 دقائق)

```bash
curl -s https://madarek.onrender.com/api/v1/health   # {"ok":true,…,buildId يطابق رأس الشجرة}
```

- افتح الصفحة العامة `/` — العنوان والزر الذهبي «ابدأ رحلتك»
  يظهران في الطية الأولى (r187).
- جرّب الوضعين: فاتح/داكن من مفتاح التبديل في الترويسة.

> بيانات «جامعة الزاوية» هي **بيانات مؤسّسة العرض المرجعية**
> (بيانات عامة لأغراض العرض) — لا ادعاء تبني رسمي.

## سردية العرض (12 خطوة)

1. **الصفحة العامة** `/` — القيمة في أول 5 ثوان، ثم شريط الكليات.
2. **تسجيل الدخول** `student@demo.madarek.ly` — يهبط في لوحة الطالب.
3. **لوحة الطالب** — المقررات النشطة والتقدّم والترحيب.
4. **مقرّر حقيقي** — من «مقرراتي» افتح مقرّرًا ثم محاضرة.
5. **مشغّل المحاضرة** — شغّل الفيديو، أجب عن نقطة التحقّق،
   لاحظ الإبلاغ عن التقدّم (تقدّم المحاضرة P0 أُصلح r181a).
6. **مكتبة** — أغلفة الكتب الطباعية (r186b) وفتح PDF حقيقي.
7. **البحث/مساعد الذكاء الاصطناعي** — قل بصدق: «يعمل الآن بالوضع
   المحلي الصادق؛ المزوّد الخارجي اختياري» (كل ردّ يُسند لمصدره).
8. **الأستاذ** `teacher@demo.madarek.ly` — إنشاء تكليف/درجة، مراجعة
   بحث، رفع مادة PDF (رفع حقيقي 20MB كحد أقصى).
9. **الإدارة** `admin@demo.madarek.ly` — كلية ← قسم ← مقرّر ← شعبة
   (الإنشاء يثبت دوام البيانات بعد التحديث).
10. **المالك** `owner@demo.madarek.ly` بالسر الخاص — لوحة المنصّة،
    المؤسسات، الحاكمية، سجل النشاط.
11. **العزل (أقوى لحظة)** — سجّل الدخول `student2@demo.madarek.ly`
    وحاول فتح ملف/مقرّر خاص بالمؤسسة الأولى → **403/404 بلا إفصاح**.
12. **الدوام** — نفّذ فعلًا (تسجيل في مقرّر) ثم أعد تحميل الصفحة.

## حساب المالك — إدارة المشغّل

- **الدخول اليوم:** البريد أعلاه + السر المُسلَّم خاصّة (لو فُقد:
  استعمل مسار الاستعادة أدناه).
- **حساب باسمك (الهوية):** عند تقديم بريدك المتحقّق للمشغّل:

```bash
node scripts/provision-owner.mjs --email <بريدك> --yes --suspend-demo-owner
# من مجلد backend/ مع DATABASE_URL للإproduction — يطبع سرًّا لمرة واحدة
```

- **تدوير أي كلمة مرور (استعادة):**

```bash
export NEW_PASSWORD="$(openssl rand -base64 24)"
npm run db:rotate-password -- --email owner@demo.madarek.ly --new-password-env NEW_PASSWORD --yes
```

## النسخ الاحتياطي (فعل المشغّل)

```bash
npm run db:backup     # نسخة إلى backups/ مع sha256
npm run db:restore -- --url-env <TARGET> --file backups/<الملف>   # إلى قاعدة عزل فقط
```

- **انقل الملف خارج الخادم** (هذه هي الخطوة المتبقّية الوحيدة —
  RPO/RTO في 12-§5).
- تجربة استعادة موثّقة: `docs/runbooks/restore-exercise-log.md`.

## حدود صادقة (قلها إن سُئلت)

- الذكاء الاصطناعي: وضع محلي صادق بلا مزوّد خارجي مفعّل.
- نسب الاستلال/المحتوى الآلي: **مؤشرات محاكاة** — ليست أدلة أكاديمية.
- مؤسسة واحدة مرجعية (الزاوية كبيانات عرض) + مؤسسة عزل للتجربة.
- النطاق: عرض جامعي وطيار 5–10 طلبة — لا ادعاء جاهزية إنتاج واسع.

## r189 — بيانات اعتماد حسابات العرض (مهم)

كلمة العرض المشتركة القديمة **لم تعد صالحة على الإنتاج** (مرفوضة 401 —
تحقّق حيّ 2026-10-19). كل حساب عرض (student/teacher/admin/quality@demo.madarek.ly)
يحمل الآن سرًّا مستقلًّا قويًّا دُوِّر عبر مسار `db:rotate-password` وسُلِّم
للمشغّل عبر القناة الخاصة مع هذا التقرير. عند فقدان أحد الأسرار: أعِد
التدوير بنفس المسار (لا تعِد بذر الإنتاج أبدًا لتغيير كلمة):
`npm run db:rotate-password -- --email <الحساب> --new-password-env NEW_PASSWORD --yes`
