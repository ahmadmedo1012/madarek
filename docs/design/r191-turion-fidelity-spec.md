# R191 — Turion Space Fidelity Specification
## المرجع كتسلسل مشاهد، لا كقائمة ألوان (The reference as a scene sequence)

> **المرجع**: https://www.turionspace.com/ — موقع **Framer**، قِيس حيًّا في Chromium حقيقي (Playwright 1.57).
> **الأدلة**: `/home/z/probes/r191-ref/` — structure JSON ×5 viewports · 78 خطوة تمرير desktop · 90 خطوة mobile · خط زمني دقيق 102 خطوة (`stage-timeline.json`) · لقطات تفاعل (hover/slider).
> **Firecrawl**: غير متاح في هذه البيئة (لا CLI، لا MCP، لا مفتاح API في أي مصدر معتمد) — مسجَّل بأمانة؛ البديل المعتمد من المهمّة: Playwright + تحليل VLM للقطات. تم استخدام VLM على سلسلة اللقطات للسرد البصري.
> **قاعدة القياس**: كل رقم أدناه مقيس من DOM حيّ أو من مصفوفة لقطات — لا تقديرات إلا الموسومة «تقدير».

## 2. تشريح المشاهد وسلوكها المقيس

### ٢.١ Hero (شاشة واحدة)
- خلفية سينمائية: أفق أرض مضيء + قمر صناعي 3D (صورة 1440×900) + خط مداري رفيع قطري.
- `h1` 72px/500 («Accelerating humanity's galactic destiny»، 1114×130 عند y=365) مع كلمات بتدرّج لوني.
- علامات قياس: `001 · ORBIT WITH PURPOSE` أسفل اليسار (14px/300، tracking واسع) — جملة المهمّة أسفل اليمين (431×39).
- مدخل متدرّج (stagger reveal)؛ عنصر `starforge` 400×400 بمعدل بارالاكس مقيس **0.20** (يتحرك بـ20% من سرعة التمرير).
- **الفرق الجوهري عن r190**: Turion يعرض لقطة سينمائية واحدة مكتفية بذاتها (أفق + جسم 3D) — ليس شبكة عناصر زخرفية.

### ٢.٢ المرحلة الكبرى — «mission areas» (المركز؛ 9,900px مثبتة)
- الحاوية `.framer-uy0p40-container`: 9,900px، بداخلها **sticky 1440×900** (الإطار المثبَّت) + SVG خريطة مدارية: دوائر متراكزة عملاقة (قطر 6,461–6,721px، مقصوصة) + عقد ومسارات + نصوص SVG (12px).
- **السرد**: عمود محتوى أعلى اليمين يتبادل محتوى (crossfade) مشهدًا بعد مشهد، بينما الخريطة تبقى مثبتة وتتغيّر حالتها.
- المشاهد المقيسة (من الخط الزمني + VLM):
  1. `002 · A SPACE CONTROL COMPANY` يدخل (الشاشة تسودّ ثم تظهر الخريطة من الأسفل) — y≈1,000–2,000
  2. `TODAY — Focused on three foundational missions` + 01/02/03 + على الخريطة علامات المهام — y≈2,000–3,000
  3. `WHY WE EXIST` + دائرتا مقارنة (كبيرة فارغة EARTH'S ECONOMY مقابل صغيرة بنفسجية SPACE ECONOMY) — y≈3,000
  4. `THE FIRST STEP` + **شريط القدرات السفلي 01–06** يدخل مع تظليل 01 DOMAIN AWARENESS — y≈4,500
  5. `THE NEXT BIG OPERATIONAL NEED` — مسار TRANSPORT يُرسم على الخريطة، تظليل 04 — y≈6,000
  6. `STEADY STATE — Efficient fleet operations` — الشبكة كلها تضيء — y≈7,500
  7. الختام/الانتقال — y≈9,000–10,800
- **ميكانيكا مقيسة**: دوران الخريطة مع التمرير (matrices: rotate −28°→−54° عند y1,050–1,650 ثم دوران مستمر ~15°→32° لعقد متنقّلة عند y≥3,300) · دخول/خروج علامات الخريطة بـopacity مرتبط بمواضع تمرير محددة (fade-in عند y3,150–3,750، إخماد تدريجي y3,750–5,850) · البيانات الوصفية أعلى اليمين تتبدّل مع كل مشهد · ملاحظة ثابتة `ORBITS NOT TO SCALE` أسفل اليمين.
- **النمط المُستخلص**: «حلقة سرد خِدَمي»: النص يعرّف الهدف ← الخريطة تحرّك حالتها لتجسيده ← شريط القدرات يؤشّر التقدّم. إحساس «تبني النظام بالتمرير».

## 4. مصفوفة التكييف — Turion → مدارك

> الفارق الجوهري في r190: طبّقنا **الرموز** (خط/لون/زاوية) وبقيت الصفحة رصة أقسام ساكنة 7,828px. r191 يبني **الميكانيكا**: التثبيت، التبادل المشهدي، البارالاكس الطبقي، المواكبة المتدرّجة.

| مشهد Turion | ما يقابله في مدارك | التقنية |
|---|---|---|
| Hero سينمائي بشاشة واحدة | مشهد «نقطة المعرفة»: فن أصلي (أفق معرفي) + خط مداري + عنوان «كلُّ معرفةٍ تبدأ نقطة، وتنمو في مدارك» + علامتا قياس (٠٠١ · جملة الرسالة) + مؤشّر تمرير | صورة مولّدة أصلية + SVG خط مداري + reveal متدرّج |
| المرحلة المثبتة 9,900px (خريطة مدارية + 7 مشاهد) | **«خريطة التعلّم»**: مسرح sticky ~6 شاشات — خريطة SVG حلقات متراكزة (المؤسّسة مركزًا، عقد: المحاضرة/المصفوفة/الاختبار/البحث/المساعد/الشهادة) + عمود سردي أعلى اليمين يتبادل 6 مشاهد: ما هي مدارك ← اليوم: ثلاث ركائز ← لماذا مدارك (دائرتا مقارنة: تعليم متفرّق/منظومة متصلة) ← الخطوة الأولى + شريط قدرات ٠١–٠٦ ← القياس ← منظومة متكاملة | sticky + محرّك تمرير rAF (`useScrollStage`) يكتب CSS vars؛ إضاءة العقد ورسم المسارات بدفع التمرير؛ rotation خفيف للخريطة؛ الملاحظة الثابتة «خريطة توضيحية» |
| Products slider (3 بطاقات) | «المنظومة» (كريمي): 3 بطاقات [٠١] المحتوى والمحاضرات [٠٢] القياس والاختبارات [٠٣] الذكاء الأكاديمي — صور أصلية + وسوم + سلايدر RTL بأسهم | CSS scroll-snap + أزرار |
| PROOF مثبَّت (إحصاءات متدرّجة) | **«ما يعمل اليوم»** مثبَّت ~2 شاشة: عنوان كبير مثبّت + 4 بطاقات تحسب **أرقامًا حقيقية من الكود** (قدرات تعمل الآن = LIVE_COUNT، ٥ أدوار، ٤ أنواع أسئلة، بيانات عرض اصطناعية معلنة ١٠٪) بمواكبة متدرّجة | sticky + scroll-progress march |
| News (3 بطاقات) | «لمن صُنعت» (فاتح): 3 بطاقات رحلة (الطالب/الأستاذ/الإدارة) + سطر صادق لمساحتي ضمان الجودة ومالك المنصّة | نفس تشريح بطاقة Turion |
| Starforge (كلمة 200px + قياسات) | «إلى أين»: كلمة «مدارك» عملاقة + بارالاكس خلفية + **أزواج حالة صادقة بلغة طبيعية**: يعمل الآن / تجريبي / قيد التطوير (من دفتر الصدق — بلا مصطلحات تشغيلية) | parallax layers + بلا أرقام مختلقة |
| Quotes (بارالاكس طبقي) | بطاقة «مبدأ مدارك»: اقتباس المبدأ (استقلال/شفافية البيانات) + لقطة حقيقية من داخل المنصّة بديلًا عن شخصية مزيّفة + علامات زوايا | layered parallax 0.03–0.07 |
| CTA فاتح | «جاهز تبدأ رحلتك؟» + أنشئ حسابك الجامعي | — |
| Footer + كلمة ضخمة | أعمدة المنصّة/الأدوار/المشروع + تنويه البيانات التجريبية + **كلمة «مدارك» عملاقة ببارالاكس صاعد** | — |
| Nav ثابت بنسخة scrolled | الترويسة الحالية + نسخة scrolled (موجودة) بعناوين جديدة طبيعية | — |

**قواعد المحتوى (بوابة صارمة)**: حذف «صُنعت في ليبيا» و«ما يُشحن اليوم» وكل مصطلح داخلي مُحرّج من كل سطح مرئي؛ عربية فصيحة طبيعية بلا حشو تسويقي؛ لا أرقام مختلقة — الأرقام تُحسب من الكود؛ بيانات العرض تُعلَن تجريبيةها بوضوح.

**تكييفات مشروعة**: RTL (عمود السرد أعلى اليمين)، أرضية طباعية للعربية (lh ≥1.05)، نظام الثيمين القائم يبقى للجسم (المسرح عائلة ثابتة داكنة كمافي r190)، `prefers-reduced-motion` = كل المحتوى مرئي بلا تثبيت/تبادل.

**الجوال**: لا تثبيت — تكديس رأسي، النص أولًا، الخريطة خلفية، الخُطوط تتقلّص (72→40px)، الكلمة العملاقة 200→72px — كما في المرجع المقيس.
