### ما غيّرته r188 (إعادة تأسيس العلامة + التحوّل البصري)

1. **هوية مستقلّة تمامًا (البوابة الأولى):** جامعة الزاوية الحقيقية
   أُزيلت من كل الأسطح النشطة (رمز/بيانات/ميتاداتا/أصول) وحلّت
   «جامعة مدارك التجريبية» الاصطناعية (25 كلية على ثلاثة حرَم، بريد
   demo.madarek.ly) عبر ترحيل معطيات idempotent مُختبر على قاعدة
   مؤسَّسة وفارغة. بوابة سلامة علامة r188 ترصد أي عودة.
2. **تحوّل «دفتر مدارك»:** إعادة تصميم كاملة لصفحة الهبوط (فصول
   مرقّمة، دفتر صدق، لوحة مخطوطة) + رؤوس صفحات فصلية عبر الهيكل
   كله (90+ صفحة) + السجل الجانبي كفهرس + النجمة علامةً للدخول.
   axe صفر مخالفات، VLM 8-10/10.
3. **كلمة مرور العرض خرجت من README العام** — التسليم عبر دليل
   المشغّل وقناة خاصة (r188). دخول المالك التجريبي المُدار (r187)
   كما هو — السر المُسلَّم للمشغّل سارٍ.

### إصلاحات r187 المُقيسة (على الشجرة الحية)

1. **إنقاذ طيّة الـhero:** زر «ابدأ رحلتك» كان يبدأ عند y=797 على
   شاشة 1280×800 (خارج الطية؛ مخفي تمامًا على حواسيب ≤768px).
   المقيس بعد الإصلاح: **693px ومكتمل الظهور** (وعند 1440×800
   يعود العنوان لسطرَيه المصمَّمَين). أنظر `--ln-h1-short`
   (tokens.css) + §5b (landing.css).
2. **صور الرموز غير المسورة (a11y):** جدولان (الطلبة في لوحة المسجل العام،
   الأستاذة في الجودة) كانا يتجاوزان بوابة حبر الصور الرمزية
   (`avatarInk`) — لون رمادي `#6B7280` يقيس 3.91:1. استُبدلا
   بالعنصر الأساسي `UserAvatar` المحكوم (≥4.5:1 دائمًا).
3. **دخول المالك التجريبي أُدير (انظر §3):** كلمة المرور المنشورة
   للعرض أُبطلت على الإنتاج؛ الحساب صار بيد المشغّل وحده.

## 3. حساب المالك (حالة تجهيز المشغّل)

- **r187 (تم):** كلمة مرور حساب العرض `owner@zu.edu.ly` **دُوِّرت**
  على الإنتاج إلى سر عشوائي قوي (24 بايت) وسُلِّم للمشغّل عبر قناة
  خاصة (هذه المحادثة) — الكلمة المنشورة القديمة صارت **مرفوضة**
  (تحقّق حي: `INVALID_CREDENTIALS`) والدخول بالسر الجديد يعمل
  عبر مسار المصادقة الفعلي (دور OWNER + وصول مسارات `/owner/*`
  مُتحقَّق حيًّا). بهذا صار حساب مالك واحد **فعليًّا بيد المشغّل**.
- **جاهز للاكتمال:** سكربت `npm run db:provision-owner` (r187)
  ينشئ حساب مالك **باسم هوية المشغّل** (بريده) بسرّ لمرة واحدة +
  صف سجل تدقيق `OWNER_PROVISION`، وي optionally يعلّق حساب العرض
  (نفس المعاملة الذرية). مُختبر محليًا من البداية للنهاية
  (إنشاء → دخول حقيقي → وصول `/owner` → 403 للطلبة → تنظيف).
  **الناقص الوحيد: بريد المشغّل المتحقّق** — أعطه للمشغّل للأمر
  (`node scripts/provision-owner.mjs --email <بريدك> --yes --suspend-demo-owner`).
- **لماذا لم يُنشأ حساب الهوية الآن؟** لا يُختلق بريد ولا تُفترض
  ملكية هوية لم تتوثّق (قاعدة الجولة). الحساب التجريبي المُدار
  يغطي الحاجة التشغيلية فورًا.
