## 1. ملخص المشروع الحالي

منصة «مدارك» هي منظومة التعليم الذكي لجامعة الزاوية (ليبيا): LMS عربية RTL
كاملة الأدوار (طالب/أستاذ/إدارة/جودة/مالك)، بُنيت عبر خمس حملات تحسين سابقة
انتهت بحالة ناضجة:

- بناء إنتاجي سليم: `npm run build -w frontend` ✓ (12s)
- 973 اختبار واجهة (84 ملفًا) + 970 اختبار خلفية — أخضر (مع اختبارٍ واحد
  «هشّ» في `QualityPages-rosters.test.tsx` سيعالَج في هذه الحملة).
- نظام تصميم «Notion-flavored» كامل: رموز (tokens) موثّقة بمعادلات WCAG،
  طبقات CSS منظمة، نظام حركة مقيَّد بالرموز، ثيم فاتح/داكن، هوية كليات بألوان
- النسخة المنشورة على Render **أقدم من HEAD** (خطأ مكتشف على المنصّة
  المنشورة أُصلح جذريًا في المستودع — التحقق النهائي يحتاج إعادة نشر).

## 5. خلاصة تحليل الموقع المرجعي (promo.emotion-agency.com)

التقرير الكامل: `audits/imm-1-reference-analysis.md` (أدلة من فحص الحزم
والشيفرة والقياسات الحية). المكدس المكتشف: Nuxt 3 + GSAP 3.12.5 +
ScrollTrigger + SplitText + Three.js r169 (694KB) + تمرير افتراضي مخصص +
Howler؛ 4.5MB حمولة، بوابة صوت قبل المحتوى (~15 ثانية)، حرفيون عاليًا لكنه
**نموذج ترويجي لا تعليمي**.

**عشرة مبادئ نتبنّاها (العمود الفقري لا الجلد):**
1. مسارٌ مؤلَّف واحد: التمرير رحلة متصلة، الأقسام «مشاهد» لا كتلًا متراصة.
2. التمرير كخط زمني: scrub للأقنعة والإبرازات عبر تقاطع viewport.
3. كشف النص بأقنعة الأسطر/الكلمات — **ممنوع تقسيم الحروف العربية** (يكسر
   الاتصال والتشكيل).
4. قائمة متسلسلة بإبراز نشط متحرك → الخط الزمني للمنهج (pill نحاسي متدرج).
5. تباين طباعي متطرف: عرض ضخم vs شارات mono دقيقة — بأرضيات عربية ≥12px.
6. صوت «ميتا» مرقّم: `( م-٠١ )`، `[#رابع-سنة]` بأرقام `--type-metric-*`.
7. تفاعل مرتد على كل قناة: label-roll للأزرار، parallax مُخمَّد بالسرعة،
   مشهد يتجاوب مع المؤشر.
8. كفاءة المشاهد: `content-visibility: auto` لما تحت الطية (بدون خطف التمرير).
9. سلاسة من «خفة العنصر» لا من خطف التمرير: lerp داخل عناصر، تمرير أصلي.
10. ضبط النفس: لوحة محدودة، لون تمييز واحد (النحاس)، مادة واحدة للزجاج.

**ما نتجنّبه حاسمًا:** خطف التمرير الافتراضي، بوابات التحميل/الصوت، WebGL/
Three.js (600KB+ وGPU)، تقسيم حروف عربية، ملصقات 8px، تعطيل التكبير/
التركيز، زجاجية منتشرة، صفحات بلا اختصارات تنقل.

## 6. الاتجاه الفني المقترح

**الفكرة الإبداعية: «مدارك = رحلة معرفة تتوسّع فيها المدارك».**

الهبوط يتحول إلى **رحلة جامعية واحدة مؤلَّفة** — من القبول إلى التخرّج —
كل مشهد يكشف طبقة من الرحلة، والعناصر البصرية (عُقَد معرفة نحاسية، مدارات،
خطوط ربط) تدعم الفهم ولا تحتفي بالمحتوى:

```
المشهد ١  البطل      — تركيب قطري RTL: عنوان ضخم بنقطة نحاسية، نبضة «مدارك»
                       حيّة (ConstellationCanvas: عقود معرفة بمدارات نحاسية
                       تتفاعل مع المؤشر وسرعة التمرير — Canvas 2D، بلا مكتبات)
المشهد ٢  الشريط     — marquee عربي هادئ لحقائق الجامعة (شركاء/أرقام حقيقية)
المشهد ٣  الحرم      — مقر الجامعة والكليات (content-visibility)
المشهد ٤  كيف تتعلم  — الخط الزمني للمنهج: قائمة متسلسلة بإبراز نحاسي
                       متحرك (scrub): الفصل المعكوس → المصفوفة → الذكاء →
                       البحوث → الاختبارات → الإنجازات
المشهد ٥  الدليل     — إحصاءات حقيقية فقط (CountUp موجودة) بصوت ميتا مرقّم
المشهد ٦  الأدوار    — بوابات الدخول لكل دور
المشهد ٧  الختام     — كلمة «مدارك» العملاقة (~16vw) نحاسية + CTA ختامي
```

الحفاظ على الهوية: أرضية كريمية `#FBFAF9`، حبر `#191918`، نحاس `#B57438`
(الداكن: `#191918`/`#F2EAD8`/`#E0A067`)، IBM Plex Sans Arabic — **لا هوية
جديدة، بل إخراجٌ أعلى لنفس الهوية**.

## 7. نظام الألوان والطباعة (إضافات رموز فقط — لا كسر)

- `--journey-*`: ألوان مشهد الرحلة (خيوط نحاسية شفافة، عقود متوهجة
  ناعمة) — WCAG-pinned كما في tokens.css الحالي.
- `--type-display-hero`: دور طباعي جديد (clamp بطبقات، أرضية 40px عربي).
- `--wordmark-size`: قياس كلمة الختام العملاقة بمنطق clamp/vw.
- `--motion-scrub-*`: منحنيات lerp للخمود (damping) داخل الرموز.
- أرضيات: لا نص فعلي تحت 12px (وحقول ≥16px لمنع تكبير iOS).

## 8. خطة الحركة (Canvas لا WebGL)

| التقنية | القرار | السبب |
|---|---|---|
| GSAP + ScrollTrigger | **رفض** | تجميد الاعتماديات؛ 95% من الاحتياج مغطى بنظامنا المقيد بالرموز؛ الفجوة (scrub) تُسدّ بـ hook بسيط؛ لا SplitText عربي أصلًا |
| Lenis / تمرير افتراضي | **رفض** | مخاطر وصول/لوحة مفاتيح/RTL مقابل ربح جمالي محدود؛ المرجع نفسه يسقطه على اللمس |

## 9. خطة RTL والموبايل والوصول

- كل الاتجاهات عبر خصائص منطقية + `--motion-direction` (موجود) — لا قيم
  فيزيائية مجردة.
- المؤشر/اللمس: المشهد الحي يتفاعل مع pointermove وdeviceorientation لا
  (بساطةً: pointer فقط)، وأهداف لمس ≥44px.
- تركيب البطل القطري يعكس نفسه منطقيًا في RTL دون قيم معكوسة يدويًا.
- الكشف النصي: أسطر/كلمات فقط؛ الحروف العربية محرم تقسيمها (قاعدة منصة).
- `prefers-reduced-motion`: Canvas يرسم إطارًا ساكنًا، وكل scrub/marquee
  يتحول لحالات نهائية فورية (النظام الموجود يضمنها — نُقيّم لا نكسرها).
- فحص لوحة مفاتيح كامل للهبوط الجديد (ترتيب تركيز، إغلاق megamenu بـ Esc،
  focus-visible واضح).

## 10. خطة الأداء و fallbacks

- `ConstellationCanvas` يُحمَّل ديناميكيًا داخل chunk الهبوط فقط، ولا يعمل
  خارج viewport (IntersectionObserver)، ويُوقف rAF عند إخفاء التبويب.
- DPR مقيد بـ 2، عدد العقود يتناسب مع المساحة، ويُخفَّض على الأجهزة الضعيفة
  (`navigator.hardwareConcurrency`).
- فشل/غياب Canvas → خلفية SVG/CSS ثابتة جميلة (نفس المشهد ساكنًا).
- `content-visibility: auto` + `contain-intrinsic-size` لكل مشهد تحت الطية.
- الصور: lazy + أبعاد مثبتة (لا CLS)؛ الخطوط self-hosted موجودة — لا تغيير.
- ميزانية: chunk الهبوط الحالي 39KB gz → المستهدف ≤ +14KB gz (الكود
  المخصص كله صغير؛ بلا مكتبات).
- قياس فعلي قبل/ بعد (vite build بالحجامة + Lighthouse عبر agent-browser).

## 11. خطة الاختبارات

- اختبارات وحدة جديدة: `useScrollProgress` (rv + rAF محاكاة)، `MaskReveal`
  (RTL/reduced-motion)، `SequentialHighlight` (ترتيب الإبراز)،
  `ConstellationCanvas` (سقوط آمن بلا canvas، إيقاف خارج الشاشة).
- تحديث واعٍ لاختبارات الهبوط المتأثرة (journey-rail، LandingPage) عند تغير
  DOM المقصود.
- إصلاح الاختبار الهشّ `QualityPages-rosters` (انتظار استقرار العدّاد).
- Gates: `build` + `typecheck` + `vitest 973+` + `check-motion-tokens` +
  `check-icons` + فحص بصري (agent-browser) على 320/390/768/1280/1440 +
  RTL + keyboard + reduced-motion.

## 12. معايير القبول

1. الهبوط رحلة مؤلَّفة واحدة: كل مشهد له لحظة كشف مرتبطة بالتمرير.
2. مشهد البطل حي (مؤشر + سرعة) بلا أي مكتبة جديدة، وبديل ساكن جميل.
3. كل النصوص تُكشف بأقنعة أسطر/كلمات RTL-safe — لا تقسيم حروف.
4. الخط الزمني للمنهج يعمل بالإبراز المتسلسل المرتبط بالتمرير.
5. الختام بكلمة عملاقة + CTA، وملصقات الأزرار الأساسية label-roll.
6. لا أخطاء console، لا CLS، لا كسر تركيب عند أي مقاس فحص.
7. reduced-motion = تجربة كاملة ساكنة صحيحة، ولوحة المفاتيح تعبر الهبوط
   كاملًا بترتيب منطقي.
8. `npm run build` + `typecheck` + الاختبارات (973+) خضراء، والسكربتات
   الحرجة تمر.
9. صفحات التعلّم الداخلية لم تتغير هويتها (فحص diff مقيَّد).
10. توثيق كامل: هذا الملف + `docs/immersive-redesign-report.md` بالأدلة.
