## 1) المفهوم الإبداعي الأصلي — «سماء مدارك»

**«مدارك = رحلة معرفة تتّسع فيها المدارك»** — الاسم نفسه (جمع: مدار) هو الاستعارة المركزية التي كانت غائبة تمامًا عن النسخة الحالية:

- **العالم البصري:** سماء ليلية ليبية عميقة — نيلي حبري يتدرّج نحو الأفق، تلمع فيه عقد معرفة ذهبية دافئة. الضوء الذهبي = ضوء المعرفة/المصباح الدراسي؛ النيلي = ليل الصحراء الهادئ. (لوحة أصلية لمدارك — لا علاقة لها ببنفسجي المرجع ولا بكريم Notion.)
- **القصة:** كل معرفة تبدأ **نقطة ضوء** ← تتّصل بغيرها فتصبح **مدارًا** ← المدارات تتجمّع فتصبح **مسارًا** ← والمسار يُتقن فيتحوّل الضوء إلى **نور جامع** (شهادة/إتقان).
- **الطبقات الثلاث** (درس مُستلهَم من حرفة المرجع، مُطبَّق بهوية مدارك):
  1. **طبقة المشهد** — مدارات Canvas حيّة تتنفس وتتفاعل.
  2. **طبقة الإنسان** — عربية ضخمة، دافئة، موجّهة للطالب والأستاذ.
  3. **طبقة النظام** — `IBM Plex Mono` (موجود في الحزمة، مُهدر اليوم) لملصقات مثل `مسار ٠١ / ٢٥` وإحداثيات التقدم.

### لوحة الألوان (نطاق `.landing` فقط — لا يُمَس نظام التطبيق الداخلي)

### الطباعة

- عنوان Hero: `clamp(44px, 9.2vw, 118px)` بوزن 700 و`--ls-display` — ضخم لكنه مقروء، سطران كحد أقصى.
- عناوين الفصول: `clamp(30px, 4.6vw, 58px)`.
- طبقة mono: ‏11–13px، `letter-spacing: 0.08em`، أرقام غربية داخل سياق عربي (أرقام القراءة الآلية) — متسقة مع `--font-mono` الموجود.
- إيقاع: سطور عربية `1.25` للعناوين (تُحترم الشدّة والتنوين)، `1.75` للنص.

## 2) قرار المكتبات (بحث + تقييم Adopt/Consider/Reject)

قرار مسبق بالبحث في التوثيق الرسمي وNPM (سجلات الموجود في التقرير النهائي):

| المكتبة | الحجم (gzip) | القرار | السبب الحقيقي |
|---|---|---|---|
| **GSAP + ScrollTrigger** | ~28KB | **رفض** | المشهد ثنائي الأبعاد بسيط التحكم؛ لدينا نظام reveal + Parallax + progress مخصص يعمل ومُختبَر (855 اختبار)؛ ScrollTrigger pinning يخاطر بلوحة المفاتيح والتمرير الأصيل الذي يشترطه التوجيه. الحركة المطلوبة تتحقق بـ rAF + IntersectionObserver + CSS بلا كلفة إضافية. |
| **Three.js / R3F** | ~150KB+ | **رفض** | مشهدنا مدارات/جسيمات 2.5D — Canvas 2D يحققها بكثافة جسيمات أعلى وكلفة أقل بكثير؛ R3F يضيف React-reconciler كامل لمنصة LMS إنتاجية. |
| **Lenis** | ~5KB | **رفض** | smooth-scroll الاصطناعي يتعارض مع `prefers-reduced-motion` ولوحة المفاتيح ومتطلبات الوصول الصارمة؛ التمرير الأصيل + حركة مشهدية بالـrAF يعطي الإحساس دون اختطاف التمرير. |
| **particles.js/tsx-emitter** | 8–20KB | **رفض** | مظاهر عامة مكررة — المشهد يحتاج مدارات فيزيائية مخصصة (نجوم تدور، مسافر يتنقل) لا جسيمات عشوائية. |
| **Canvas 2D API (بدون مكتبة)** | 0 | **تبنٍّ** | تحكم كامل: مدارات إهليلجية، جاذبية ماوس خفيفة، trail للمسافر، DPR-cap، إيقاف خارج الشاشة، بديل ثابت لـreduced-motion. |
| **CSS + hooks مخصصة (الموجودة)** | 0 | **تبنٍّ (توسيع)** | `useReveal`/`Parallax`/`CountUp` موجودة ومختبَرة — تُعاد صياغتها بصريًا داخل العالم الجديد. |

**النتيجة: صفر اعتماديات جديدة.** كل الحركة CSS + Canvas 2D + rAF داخل مكون واحد معزول.

- `.landing` تفرض عالمها الداكن بغضّ النظر عن `data-theme` — سطح تسويقي سينمائي ثابت الهوية (مثل صفحات المنتجات السينمائية)؛ داخل التطبيق يبقى على نظامه الفاتح/الداكن الحالي دون مساس.

## 5) مواصفات محرك المشهد (OrbitScene)

- **طبقات:** نجوم خافتة (twinkle بطيء) ← مسار درب التبانة القطني (noise بسيط مرسوم مرة) ← 4 مدارات إهليلجية بشفافية `--ln-mist` تحمل عقدًا ذهبية/زرقاء ← «المسافر»: نقطة ضوء ساطعة بذيل متلاشي تدور وتنتقل بين المدارات ← خطوط اتصال تُرسم بين العقد القريبة (constellation).
- **التفاعل:** على أجهزة hover فقط — الماوس ينجذب للعقد بلطف (جاذبية عكسية خفيفة) + parallax للطبقات؛ على اللمس: ثبات أنيق بدون جاذبية.
- **التقدّم:** `--scroll` من التمرير يوسّع المدارات حتى 12% ويخفت التوهج — إحساس الكاميرا تتراجع.
- **الأداء:** `requestAnimationFrame` واحد؛ DPR ≤ 2؛ عدد النجوم/العقد دالة في مساحة الشاشة (≤ 90 نجمة، ‏≤ 14 عقدة)؛ إيقاف كامل خارج الشاشة (IO)؛ `saveData`/`deviceMemory≤2` = كثافة مخفّضة؛ `prefers-reduced-motion` = **رسمة ثابتة واحدة عالية الجودة** (بلا حلقة).
- **الفشل الآمن:** أي استثناء في Canvas ⟵ يُخفى بـ`opacity:0` وتظهر خلفية CSS متدرجة بديلة غنية (radial + نجموم SVG pattern) — الصفحة كاملة الوظائف بدونه.

## 6) خطة الاختبار والقبول

- مقاسات: 320/390/768/1024/1280/1440 + تدوير.
- فحص: RTL، لوحة مفاتيح (tab عبر كل التفاعلات)، reduced-motion (محاكاة)، console صفر أخطاء حرجة، WebGL/Canvas فشل مفتعل.
- أوامر: `npm run typecheck` و`npm test -w frontend` و`npm run build` — كلها يجب أن تمر.
- تقييم VLM قبل/بعد على Hero والصفحة الكاملة (1440 + 390) — هدف ≥ 8/10.
- حفاظ صريح: CollegesPopover، روابط nav/footer، التسجيل، الثيم الداخلي، الصفحات الداخلية.
