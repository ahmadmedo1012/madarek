# خطة إعادة البناء الجذري v4 — «عالم مدارك: المعرفة في حركة»

> **الإصدار:** v4 (تحل محل خطة immersive-v2 بالكامل) · **التاريخ:** 2026-09-27 · **مرجع القرارات:** docs/radical-redesign-gap-analysis.md

## 1. الفكرة المركزية

مدارك = **رحلة معرفة تتّسع فيها المدارك**. كل طالب نقطة ضوء تدخل نظامًا، وتتحرك عبر مدارات (كليات → مقررات → إتقان)، ويكبر مدارها مع كل خطوة. اللغة البصرية:

- **نواة المعرفة** — كرة مضيئة تتنفس (ضوضاء simplex إزاحية + حافة fresnel ذهبية): المعرفة ككائن حي.
- **مدارات الكليات** — ثلاث حلقات مائلة تحمل 27 عقدة مضيئة (25 كلية + وفرة): الانتماء الأكاديمي كنظام مداري.
- **غبار المعرفة** — 1600 نقطة شيدر (ذهبي/أزرق/كريمي): أثر كل درس.
- **خيوط المعرفة** — أقواس رفيعة تربط النواة بالعقد: الفهم يربط المفاهيم.
- **خط الضوء** — خيط ذهبي يرسم رحلة التعلم عبر المحطات.
- **المدار يتّسع** — أقواس تقدم تمتلئ بالتمرير داخل فصل مثبّت: النمو ملموس.

الانتظام اللوني: ليل كحلي واحد (`#05070F→#101731`)، حبر كريمي، **الذهبي لهجة واحدة صارمة**، أزرق سماوي للمعلومات الثانوية فقط. لا أسود نقي، لا ظلال ساقطة، لا تدرجات زخرفية.

## 3. عمارة الصفحة الرئيسية (8 مشاهد)

0. **المقدمة** (زيارة أولى بالجلسة فقط): طقس دخول 1.7 ثانية — «مدارك» يعلو + سجل معرفة أحادي + عداد + مسح كاشف. تخطى بالنقر، غائب كليًا مع reduced-motion.
1. **المدار** (هيرو): عالم WebGL كامل الشاشة خلف النص؛ عنوان Cairo 800 بسلسلة `clamp(56px, 9.2vw, 148px)`؛ **التوازن غير المتماثل**: النص يحتضن حافة RTL-البداية والعالم يملك اليسار؛ كشف أسطر مقنّع (تتابع 130ms، expo-out)؛ CTA ذهبي مغناطيسي.
2. **الثقة**: شريط marquee لا نهائي RTL (توقف عند hover، صف ثابت مع reduced-motion).
3. **مدارات الكليات**: الكوكبة الحقيقية (25 زر كلية) بمدارات مجالات متوهجة.
4. **رحلة التعلم**: خط الضوء المحسوب من مواضع البطاقات + **المحطات تُضاء عند وصول الخط** (toggleClass عبر ScrollTrigger).
5. **قصة التقدم** (فصل مثبّت): تثبيت 100vh+170% — 4 أقواس مدارية تمتلئ بالفرك + صفوف إحصاء تُضاء تباعًا (أرقام دراسة الصف المعكوس الحقيقية) + نبضة نواة.
6. **الأرض**: صورة الحرم full-bleed مع parallax مكسوب.
7. **الأدوار**: أرقام Cairo 900 مجوّفة بحد ذهبي + اقتباسات تنكشف بالتركيز.
8. **نقطة البداية**: خاتمة سينمائية بحلقات مدارية دوّارة.

## 4. عقد الحركة

- **المدة/الانسياب:** كشف الدخول 600–1100ms بـ expo-out (`cubic-bezier(0.16,1,0.3,1)`)؛ التتابع 70–130ms؛ الحركة المحيطة 20–90s.
- **قواعد صارمة:** transform+opacity فقط للكشف · لا احتجاز تمرير (Lenis على التمرير الأصلي) · `prefers-reduced-motion` = نسخ كاملة ساكنة (وليس عناصر مخفية) · كل listener/animation يُنظّف (useGSAP/gsap.matchMedia revert) · الرسم يتوقف خارج الشاشة/التبويب.
- **بوابات قدرة المشهد:** WebGL2/1 متاح + لا saveData + ≥2 أنوية → تحميل idle للمشهد؛ خلاف ذلك سماء CSS كاملة الوقار. reduced-motion → إطار واحد مستقر.
