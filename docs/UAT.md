# UAT — جولة قبول كل مقعد (٣٠ دقيقة للمقعد)

> R357 L8. الجولة اليدوية التي يجريها المالك (أو من ينوب) قبل أي عرض.
> كل مقعد: ٣٠ دقيقة، بالترتيب، على `madarek-app.vercel.app`.
> علّم ✅ أو سجّل الملاحظة. أي ✗ → افتح Issue بعنوان «UAT: …».

## طالب — student@test.ly (12345678)

1. الدخول → اللوحة تظهر الترحيب والإحصاءات.
2. المقررات → افتح مقررًا → محاضرة → شغّلها وأجب عن نقطة تفتين.
3. الاختبارات → ابدأ اختبارًا → أجب → سلّم → النتيجة تظهر.
4. المساعد الذكي → اسأل سؤالًا عن مقررك → إجابة موثّقة بالمصادر.
5. الإشعارات → القراءة والتصفير.
6. التدريب → كتالوج المسارات → سجّل في مسار.
7. الخروج ثم الدخول → كل شيء كما تركته.

## أستاذ — teacher@test.ly

1. لوحة الأستاذ → عروضك التدريسية.
2. الحضور والغياب → سجّل حضور جلسة.
3. الدرجات → أدخل درجة → حفظ.
4. الذكاء الأكاديمي → قائمة مخاطر الطلاب.
5. الخروج والدخول.

## رئيس قسم — head@test.ly / عميد — dean@test.ly

1. لوحة الأستاذ (نفس السطح — النطاق على الخادم).
2. الذكاء الأكاديمي → متابعة القسم.
3. مجتمع الكلية.

## المسجل العام — registrar@test.ly

1. لوحة المسجل → الإحصاءات.
2. دليل الأشخاص → ابحث بالاسم ثم برقم جامعي ثم بهاتف — النتائج صحيحة والمسجل يرى الهاتف.
3. ملف طالب → الصورة + وثيقة (رابط موقّع يفتح).
4. استيراد Excel → رفع ملف → **وضع الفحص** → تقرير الأخطاء → لا تؤكد التنفيذ.
5. إعلان → انشر إعلانًا تجريبيًا (سيصل كإشعار دفع).
6. البريد → سجل التسليم.

## مسجل كلية — faculty@test.ly

1. نفس يوم المسجل العام — النتائج محصورة بنطاق الكلية (لا يرى خارجها).

## مراقب امتحانات — exams@test.ly

1. طابور مراجعة الاختبارات → معاينة قالب → اعتماد/رفض.

## موظف جودة — quality@test.ly

1. لوحة الجودة → المؤشرات.
2. التنبيهات التشغيلية.

## المالك — owner@test.ly

1. المؤسسات → شجرة الجامعة.
2. المستخدمون → جدول الصلاحيات.
3. النظام → حالة المنصة (buildId == آخر التزام في GitHub).

## التطبيق (Android)

1. ثبّت أحدث APK من إصدار `android-latest`.
2. دخول الطالب → كل شاشة تعمل كالويب.
3. الإشعار التجريبي (إعدادات المنصّة ← «إشعار تجريبي») يصل والتطبيق مفتوح.
4. أغلق التطبيق → إعلان من المسجل → يصل مقفلًا خلال ثوانٍ.
