# مركز توثيق مدارك

هذا المجلد هو المرجع الهندسي الكامل لمشروع **مدارك** — منصة التعلم الذكية
لجامعة الزاوية. التوثيق مقسوم إلى طبقتين متكاملتين:

1. **الدليل العربي المرقّم (01–16)** — الشرح المفهوم للجميع: من غير
   المبرمج الذي يريد فهم المشروع وإدارته بمساعدة وكلاء الذكاء الاصطناعي،
   إلى المطور الذي سيعدّل الشيفرة.
2. **المراجع التقنية المولّدة (أسماء إنجليزية)** — جداول دقيقة مستخرجة من
   الشيفرة (مسارات API، نماذج قاعدة البيانات، بنية الواجهة، الأسرار،
   المواصفات). تبقى بالإنجليزية لأنها مراجع بحث سريع تقني.

> **قاعدة الذهب:** الشيفرة هي مصدر الحقيقة. إذا اختلفت وثيقة عن السلوك
> الفعلي فالشيفرة تفوز — ويرجى تصحيح الوثيقة في نفس التغيير.
