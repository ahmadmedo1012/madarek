## 1. ملخص ما تم تغييره

أُعيد بناء الصفحة الرئيسية كرحلة جامعية واحدة مؤلَّفة بسبعة مشاهد، وأُسّست لغة حركية غامرة **بصفر اعتماديات جديدة**، مع محاذاة صفحات الدخول والرؤية، وإصلاحات جودة شاملة:

| المشهد | ما بُني |
|---|---|
| البطل | تركيب قطري RTL غير متماثل + مشهد «مدارك تتوسّع»: عقود معرفة نحاسية بثلاثة مدارات حول نواة (Canvas 2D، عدسة مؤشر، توسّع مع التمرير) + عنوان بأقنعة كلمات + نقطة نحاسية + label-roll للأزرار |
| الشريط | marquee عربي لحقائق الجامعة (اتجاه RTL مثبت بالقياس) |
| الحرم | ذروة الصورة (كما كانت) + كفاءة content-visibility |
| رحلة المعرفة | خط زمني متسلسل بست مراحل ( م-٠١..م-٠٦ ) يُضاء بالتمرير (scrub) + شريط الفصل المعكوس كعرض تطبيقي |
| الدليل | فسيفساء غير متماثلة بأكواد وحدات ( ن-٠١..ن-٠٥ ) بصوت الميتا |
| الأدوار | دفتر الأدوار (كما كان) |
| الختام | كلمة «مدارك» العملاقة (clamp حتى 240px) مقصوصة الوثبة + CTA بـ label-roll |

## 2. المكوّنات الجديدة/المعاد بناؤها

**بدائل حركة جديدة (components/motion/):**
- `useScrollProgress.ts` — أساس scrub: IO + rAF-lerp، كمّيّ تحت reduced-motion، بوابات إيقاف (188 سطرًا)
- `MaskReveal.tsx` — كشف نصوص بأقنعة **كلمات** (لا حروف — قاعدة عربية) بأقنعة تسمح بذيول الحروف (84)
- `SequentialHighlight.tsx` — قائمة الإبراز المتسلسل المرتبط بالتمرير (102)
- `ConstellationCanvas.tsx` — مشهد العقود: DPR≤2، كثافة حسب العتاد، إيقاف خارج الشاشة/التبويب، إطار ساكن لـ reduced-motion، ألوان من الرموز عبر MutationObserver (410)

**مشاهد الهبوط (components/landing/):** `HeroScene` (245)، `KnowledgeJourney` (184)، `BentoScene` (138)، `CloseScene` (61)، `TickerScene` (54) — كل مشهد يملك CSS خاصته (landing-hero/journey/bento/close/ticker.css، مجموع 1036 سطرًا في `@layer pages`).

**بنية تحتية:** `usePageTitle.ts` (عناوين مسارات)، `GridOverlay.tsx` (أداة QA بـ ?grid=1)، رموز `--journey-*` بالثيمين، أوراق أنماط المشاهد.

**أُعيد استخدامها كما هي:** JourneyRail، SectionAccent، RevealCssClass، CountUp، CollegesPopover، mockup لوحة الطالب الحقيقية، شريط الحرم، فسيفساء الجودة/الأدوار، صفحات التعلّم الداخلية كلها (لم تُمسّ — قرار الخطة §3).

## 3. المكتبات

**صفر مكتبات جديدة.** القرارات الموثقة (الخطة §8 + تحليل المرجع §7):

- لا أصول خارجية إطلاقًا — كل المشاهد مرسومة برمجيًا بألوان الهوية.

## 5. القياسات الفعلية

- **الحزمة**: LandingPage.js 39.40→**47.20KB** خام (+14.49KB gz بعد 19.71KB... دقيقًا: gz 10.94→14.49KB أي **+3.55KB gz** — داخل ميزانية الخطة ≤+14KB). CSS الهبوط: 44.46KB (−5.2KB بعد كنس 37 كتلة CSS ميتة).
- **الأداء الحي** (رأس Chromium بلا قيود عبر QA): **LCP≈464ms، CLS=0.0000**، 0 تجاوز أفقي في 7 مقاسات (320/390/768/844landscape/1280/1440/1920).
- **المشهد**: لوحة canvas ترسم وتستجيب للمؤشر (فُحص بفروق البكسل)، وكثافة تُخفَّض على ≤4 أنوية.
- **التباين**: نقطة شريط داكن أصلح من 3.30:1 → **5.95:1** (P1-1). كل الأكواد الميتا ≥AA في الثيمين (حُسبت).
- **الوصول**: skip-link جديد، ترتيب تركيز 15-tab بلا فخاخ، megamenu بـ Esc+إعادة تركيز، aria-expanded صادقة الآن (أُزيل كشف :focus-within الكاذب)، أهداف لمس 56px.
- **RTL**: القطر البطل مثبت قياسًا (حافة CTA أخفض بـ 438px من حافة العنوان عند ≥921px)، اتجاه الشريط مثبت (الدخول من اليسار)، كل الخصائص منطقية.

## 8. القيود الواقعية (بلا تجميل)

1. **لم يُنشر على الإنتاج** — الفرع جاهز؛ الدمج عبر PR يشغّل نشر Render (المنصّة المنشورة حاليًا أقدم من HEAD أصلًا).
2. **القياس الحي جرى على Chromium headless محلي** (vite preview) — لم تُختبر متصفحات فعلية Firefox/Safari يدويًا من هذه البيئة؛ الاختبارات الوحدوية تغطي المنطق لا الرسم.
3. **Lighthouse كامل لم يُشغَّل** (يتطلب بيئة نشر عامة) — استُخدم LCP/CLS الحي من PerformanceObserver عوضًا.
4. **صفحات التعلّم الداخلية لم تُعد تصميمًا** — قرار مقصود (الخطة §3: «المعلومة هي البطل»)؛ صُقلت في حملات سابقة.
5. `/vision` يتطلب تسجيل دخول (سلوك قائم) — قرار منتج متروك للمالك؛ الوصفة جاهزة إن رُغب بعلنيته.
6. القياسات على جهاز واحد سريع؛ الأجهزة الضعيفة محاكاةً عبر heuristics الكثافة فقط.
