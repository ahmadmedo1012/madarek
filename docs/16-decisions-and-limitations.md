## ب) محاكاة مقصودة معلنة (لا تُقدَّم كأنها حقيقية)

1. **فحص الانتحال/المحتوى الآلي**: نسب حتمية مُصنَّعة (انتحال 3–20%،
   آلي 4–25% بعتبتَي 15/25) — فقط استخراج نص PDF حقيقي. مكان:
   `learning.routes.ts::scanResultsFor`. أي لوحة جودة تعرض هذه النسب
   تعرض ناتج المحاكاة، وبالتالي لا يمكن أن تظهر قيم خارج المدى.
2. **«اقتراح المنهج»**: مطابقة كلمات مفتاحية قالبية — لا نموذج لغوي.
3. **zu-sync**: مصدر حقائق ثابت منسّق (بلا كشط حي) بواجهة قابلة
   للاستبدال بجالب حقيقي لاحقًا.

هذه المبادئ مستمرة في تعليقات الشيفرة نفسها — عند تطويرها لاحقًا أزل
الوسم «محاكاة» من كل السطوح المرتبطة دفعة واحدة (اختبارات تثبّت بعض
الرسائل).

## ج) قيود فنية معروفة (مقبولة الآن، مسماة بوضوح)

| القيد | الأثر | متى يجب معالجته |
|---|---|---|
| حالة تشغيلية في الذاكرة (حدود معدل، كاش قدرات، خنق تنبيهات، حراس تزامن المجدول) | تُعاد عند إعادة التشغيل؛ تتفرق بين نسخ متعددة | قبل أول توسع أفقي — مخزن مشترك (Redis/pg) |
| refresh بلا جدول جلسات | إبطال انتقائي لجهاز واحد غير ممكن | مع طلب «إدارة الأجهزة» |
| الدور داخل access JWT | تخلف حتى 15 دقيقة بعد تخفيض دور | قبول حالي (TTL قصير) |
| لا اختبارات تكامل/DB ولا E2E | منطق المعاملات والأقفال غير مثبت اند-تو-اند | قبل تغييرات مخطط كبيرة أو توسع فريق |
| `surface-baseline.json` فارغ | بوابة انزياح الأسطح تتجاوز (تجاوز صادق) | specs/012 T142 — التقاط أساس حقيقي |
| لا i18n (مُغلق نهائيًا r137) | كل النصوص عربية صريحة؛ حُذفت البوابة (`check-i18n-coverage.sh`) وعقد `locale.md` بالكامل — العربية أولًا قرار منتج لا نقص تنفيذ | طلب إصدار إنجليزي مستقبلي = مواصفة جديدة |
| قرص Render زائل | لا رفع ملفات — `fileUrl` روابط/ملفات مقدمة | قبل أي ميزة رفع: disk أو S3/R2 |
| `NODE_VERSION` غير مثبتة على Render | انحراف ممكن عن Node 22 داخل نطاق engines | توصية: تثبيت `NODE_VERSION=22` في render.yaml (لم يُنفذ — إعدادات نشر لا تُغير دون مبرر) |
| لا إجراء backup موثق داخليًا | الاعتماد على أدوات Neon | وثيقة استعادة مكتوبة + تجربة عملية |
| `check-i18n-coverage.sh` و`check:csp-hash` خارج CI سابقًا | csp-hash أُدخل إلى CI (2026-10-10)؛ سكربت i18n حُذف بالكامل في r137 (كان يتجاوز بصمت لطبقة لم تُبنَ) | — |

## د) فجوات وظيفية مرصودة (وليست أخطاء)

1. **`/teacher/exams` غير مسجل**: عنصر تنقل «بنك الأسئلة والاختبارات»
   موجود وصفحته (`ExamAuthorPages.tsx` ~2400 سطرًا) مبنية ومختبرة
   (وحدة)، لكن `App.tsx` بلا المسار — النقر يعيد للوحة الأستاذ.
   المعالجة: تسجيل المسار عند قرار تشغيل الميزة (شغل ميزة كامل لا نصفه).
2. **عدّ الكليات المزدوج**: سجل الواجهة 25 كلية (config موثق)، بينما
   حقيقة `collegeCount` المُقدَّمة من zu-sync تساوي 26 (قائمة الجامعة
   الرسمية). README يوازن بينهما صراحة — لا تغيّر أحد المضلعين دون
   قرار يحدد المرجعية.
3. **Popover/Lightbox** بلا مستهلكين في التطبيق — «مثبتة بعقد» موثق
   داخل `overlays/index.ts`؛ لا تحذفها ولا تستخدمها عشوائيًا.
4. **`useResources.ts` (~2600 سطرًا، ~120 هوكًا)** نقطة اندماج ساخنة —
   أي تقسيم لها إعادة هيكلة حقيقية تحتاج نطاقًا محدودًا واختبارات كاملة.

## هـ) ما لا يمكن حسمه من داخل المستودع (فجوات تحقق)

- صلاحيات حساب Render/Neon والإعدادات الحية.
- الاستخدام الحقيقي وسجلات التشغيل بعد آخر نشر.
- ما إذا كانت جولات specs غير الموجودة (005–010) تعيش على فروع بعيدة.
