# Visual identity layer: glassmorphism, particles, audio cues, accent theming (v2)

This change adds a 738-line CSS enhancement layer (`global-icon.css`) providing glassmorphism, particle effects, deep tinted shadows, border-shimmer hover effects, Oasis widget glow rings, morphing blob animations, and subtle gradient overlays. It also introduces a Web Audio API hook for click/success/notification sounds, a Zustand-persisted accent color picker with 6 presets, dark mode refinements, and section-specific skeleton components. A prior task's code (OasisWidget, DashboardCustomizer, i18n, code splitting, GlobalSearch) ships in the same diff.

**Watch for:** The dead `gi-progress-ring-fill` keyframe animates `background:` (non-interpolatable) and is never referenced — harmless but dead code (confirmed). The `manualChunks` array paths in `vite.config.ts` may not match Vite's resolved module IDs, potentially falling back to default splitting (possible, out of scope from prior task).

**Verdict**: APPROVED

## High-level view

All seven issues from the v1 review have been addressed. Glass tokens carry inline fallback values (`12px`, `rgba(...)`) making the glassmorphism layer resilient to missing upstream definitions. `will-change` was removed from particle pseudo-elements (only `.morph-blob` retains it for `border-radius`, which is justified). The AudioContext calls `ctx.resume()` when suspended, recovering from browser auto-play policy. The `@property --progress-angle` registration enables conic-gradient interpolation. The accent color override is documented as intentional. OasisWidget messages are capped at 50 with `as const` role literals fixing the type mismatch.

The ErrorBoundary wraps Suspense in App.tsx, and GlobalSearch uses `useMemo`-computed `sectionOffsets` instead of the mutable `runningIdx`.

## Dead keyframe: gi-progress-ring-fill

The `@keyframes gi-progress-ring-fill` block (lines 422–435) tries to animate the `background` shorthand between two `conic-gradient()` values. CSS cannot interpolate between gradient values — the browser will perform a discrete swap at 50% progress. No element references this keyframe via an `animation:` property, making it dead code left over from an earlier approach before the `@property`-based `gi-progress-ring-animate` solution was adopted.
