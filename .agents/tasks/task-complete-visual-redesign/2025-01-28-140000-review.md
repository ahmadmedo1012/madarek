## Table zebra-striping hover path

The three rules in play:

```css
.tbl tbody tr:nth-child(even) td { background: var(--surface-2); }
.tbl tbody tr:hover td { background: var(--surface-2); color: var(--text); }
.tbl tbody tr:nth-child(even):hover td { background: var(--surface-3); }
```

In dark theme, `surface-2` is `#292e38` and `surface-3` is `#313742` — clearly distinct (~8 hex steps per channel). In light theme, `surface-2` is `#f1f4f7` and `surface-3` is `#e4e9ef` — perceptible but subtle (~13 decimal steps). On a low-contrast display the light-theme hover on even rows could be missed.
