# Rebranding from "الزاوية" to "مدارك" with landing page visual polish

The change replaces the old university-affiliated brand ("الزاوية / جامعة الزاوية") with the product-first "مدارك" identity across landing page, header, sidebar, footer, search, and app shell fallback. The ministry affiliation strip is removed entirely, and the landing hero section gets richer gradients, larger padding, a sticky glassmorphism header, brand-text styling, and a glow effect on the hero image. The old `zu-mark.svg` asset reference is swapped for `madarek-mark.svg` (which exists on disk). CSS for the removed ministry strip is cleaned out from both `landing.css` and `responsive.css`.

**Watch for:** Incomplete rebrand — the old name "الزاوية" still appears in at least four other files not touched by this diff (confirmed). The sticky header's glassmorphism border is nearly invisible in light mode (likely).

## High-level view

The text rebrand covers every user-facing string in the landing flow and shell components, but misses several other frontend pages and seed data where "الزاوية" persists — creating an inconsistent identity once a user navigates past the landing page. The ministry strip removal deletes both the JSX and all associated CSS including responsive rules. The CSS visual enhancements are additive — sticky positioning, backdrop-filter, gradient tweaks, and a hover glow pseudo-element — all using existing design-token infrastructure. The sticky header's reliance on `--glass-border` produces a near-invisible border in light mode that needs a different token or a box-shadow fallback.

The seed data and design docs may be intentional (geographic references, historical content), but the two frontend pages show the old brand in user-facing UI text. A user navigating from the rebranded landing page into the admin or student sections will still see "جامعة الزاوية" — an inconsistent identity. (confirmed)

## Sticky header glassmorphism in light mode

In light mode, `--glass-bg` resolves to `rgba(255, 255, 255, 0.70)` and `--glass-border` to `rgba(255, 255, 255, 0.80)`. A white border on a white-ish blurred background is effectively invisible. The `border-radius: 0 0 var(--r-xl) var(--r-xl)` on the bottom corners hints at a card-like presence, but without a visible border or shadow, the header's extent is unclear when scrolled over content. A `box-shadow` or a `--border`/`--border-strong` token for the bottom separator would provide the necessary contrast. (likely)

## Orphaned asset

`frontend/public/brand/zu-mark.svg` is still present on disk. No references remain in the codebase after this diff. It should be deleted to keep the brand directory unambiguous. (confirmed)
