# Renders — R314 ink-render programme (§4.1)

Generated by `scripts/r314/ink-render.mjs` (deterministic, seeded — re-running
reproduces byte-identical output). Converts Madarek's own Commons-licensed
campus photos into **rich tonal pencil/ink architectural renderings**:
solid XDoG ink strokes (2–4 px weight at 1600 w), broken hand-wobbled
cross-hatch mid-tones, clustered stippled deep shadows, graphite wash tonal
ladder, paper-white sky.

licence (CC BY-SA / CC BY / PD) is inherited and kept, per-image attribution
is in `../manifest.json → renders[]`. Derivatives are marked `adapted: true`.
